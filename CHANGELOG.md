# Changelog

## 1.2.0

- Add manual-scroll, automatic-overlap long screenshots with pause, retry, finish and cancellation.
- Add a scrollable long-image editor retaining native-resolution export and existing annotation tools.
- Add screenshot translation with selectable languages, editable OCR source and copyable output, using macOS 15+ Apple Translation.
- Add bounded Unicode-preserving translation chunking.
- Make SDK/CPU selection portable; add open-source documentation, MIT license and CI.

## 1.1.0

- Add configurable persistent shortcuts, exclusive conflict detection and single-instance protection.
- Improve annotation controls: direct colors, font size, line widths, filled shapes, double-ended arrows, highlighter, number markers, eraser and blur.
- Add Vision OCR and pinned screenshots.
- Make clear/delete actions undoable and improve text wrapping and native shortcut dispatch.
- Remove duplicate local development app registrations during installation, preserving recovery archives.

## 1.0.0

- Initial native region capture, annotation, mosaic, undo/redo, PNG saving and clipboard export.
